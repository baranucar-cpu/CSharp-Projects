# C# Projects

This repository contains the C# projects I completed during my .NET and C# coursework. Each project focuses on different programming concepts such as classes, methods, interfaces, inheritance, polymorphism, MVC architecture, and Entity Framework. Together, they represent my progress in learning how to build real applications using C# and .NET technologies.

---

## PackageExpress
PackageExpress is a console application that calculates shipping quotes based on user‑provided package dimensions and weight. The program validates inputs, applies business logic, and outputs a final quote. This project helped me practice conditional statements, arithmetic operations, and user interaction in console applications.

---

## MethodPractice
MethodPractice is a C# console application designed to demonstrate method overloading, parameter handling, and return values. It focuses on building clean, reusable methods and understanding how overloading works in real scenarios. This project strengthened my understanding of class structure and method design.

---

## IQuittableDemo
IQuittableDemo showcases interfaces, inheritance, and polymorphism. The project includes an interface implementation and demonstrates how different classes can share behavior through polymorphism. It also includes object comparison logic to show how interfaces can be used to unify functionality across multiple classes.

---

## EmployeeOperatorOverload
EmployeeOperatorOverload is a console application that demonstrates operator overloading in C#. It allows custom comparison logic between Employee objects using overloaded operators. This project helped me understand how operator overloading works and how it can make object comparisons more intuitive.

---

## Insurance.MVC2
Insurance.MVC2 is an ASP.NET MVC web application that mimics a car insurance website. It collects user policy information, calculates insurance quotes using business logic, and stores the results. The project also includes an admin page where staff can view all issued quotes. It uses MVC architecture, Razor views, controllers, and Entity Framework for data access.
