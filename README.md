# C# Projects

This repository contains several C# projects I completed during my .NET coursework.  
Each project focuses on a different core programming concept such as classes, methods, interfaces, inheritance, polymorphism, and input validation.

---

## PackageExpress
A console application that calculates shipping quotes based on package dimensions and weight.

**Key Concepts Learned:**
- Input validation  
- Arithmetic operations  
- Method structure  
- Basic user interaction  

---

## MethodPractice
A C# console app demonstrating method overloading, parameters, return types, and class structure.

**Key Concepts Learned:**
- Method overloading  
- Passing parameters  
- Returning values  
- Clean code structure  

---

## IQuittable Interface Project
A project showcasing interfaces, inheritance, polymorphism, and object comparison.

**Key Concepts Learned:**
- Creating and implementing interfaces  
- Inheritance  
- Polymorphism  
- Comparing objects
